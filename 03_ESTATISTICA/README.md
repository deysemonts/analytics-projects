# Estatística

Esta pasta reúne meus estudos em estatística aplicada à análise e ciência de dados, com foco em interpretação correta dos dados e tomada de decisão baseada em evidências.

## O que estou desenvolvendo aqui
- Estatística descritiva
- Probabilidade
- Inferência estatística
- Interpretação de métricas e resultados

## Principais conceitos
- Média, mediana, desvio padrão
- Distribuições
- Correlação
- Testes estatísticos
- Overfitting e underfitting

## Aplicação no negócio
A estatística é essencial para validar hipóteses, entender variações nos dados e evitar decisões baseadas apenas em intuição ou ruído.
