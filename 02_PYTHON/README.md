# Python para Análise de Dados

Esta pasta concentra meus estudos e práticas em Python aplicados à análise de dados, com foco em resolução de problemas reais de negócio.

## O que estou desenvolvendo aqui
- Lógica de programação aplicada a dados
- Manipulação de dados com listas, dicionários e funções
- Automação de tarefas analíticas
- Leitura, tratamento e exportação de arquivos (CSV, Excel)

## Ferramentas e conceitos
- Python
- Jupyter Notebook
- Boas práticas de código
- Estruturação de scripts para análise

## Aplicação no negócio
Uso Python para automatizar análises repetitivas, preparar dados para visualização e apoiar decisões baseadas em dados de forma mais eficiente.
