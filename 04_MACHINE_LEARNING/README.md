# Machine Learning

Nesta pasta concentro meus estudos iniciais em Machine Learning, aplicando modelos preditivos a problemas de negócio de forma prática e interpretável.

## O que estou desenvolvendo aqui
- Conceitos fundamentais de Machine Learning
- Modelos supervisionados
- Avaliação de modelos
- Interpretação de resultados

## Técnicas estudadas
- Regressão
- Classificação
- Métricas de avaliação
- Treino, validação e teste

## Aplicação no negócio
Uso Machine Learning para criar modelos que ajudam a prever comportamentos, apoiar estratégias de crescimento e melhorar decisões operacionais.
