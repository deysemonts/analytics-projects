# Analytics Projects

Repositório criado para organizar estudos e projetos práticos em Análise de Dados.

## Objetivo
Consolidar o aprendizado em SQL, Python, Estatística e Machine Learning por meio de projetos práticos e documentados.

## Estrutura
- SQL: consultas, modelagem e análises exploratórias
- Python: automações, scripts e análises
- Pandas: manipulação e análise de dados
- Estatística: testes de hipóteses e inferência
- Machine Learning: modelos preditivos

Os projetos serão adicionados progressivamente conforme os estudos avançam.
